A Perl-based media automation utility for merging standalone movie commentary tracks with existing digital video files while preserving the original video stream. The application coordinates ffprobe, ffmpeg, and SoX to analyze source media, select the appropriate audio processing pipeline, and produce merged output supporting mono, stereo, and 5.1 surround audio. Configuration files provide configurable audio mixing and reproducible processing. It's a bit overdesigned in some ways, e.g. child process management. The project served as an opportunity to develop and apply Unix process-control, interprocess communication, and signal-handling skills.
